HOW TO PLAY

このゲームのルール

プレイヤーが交互に石を取り、相手の直前の取得数を繰り返さないように進めます。

  1. 11個以上、残りの石以下を取る
  2. 2直前のプレイヤーと同じ個数は取れない
  3. 3合法手がなくなったプレイヤーが負け

判定のしくみ（研究用）

各山の大きさ n について、そこから相手を負け局面にできる取得数の集合を Tₙ とします。Tₙ が空なら初手は負け局面です。直前に j 個取られている場合は、Tₙ が空か、Tₙ={j} のとき負け局面です。必勝手は Tₙ から j を除いた数です。

T₀ = ∅,　Tₙ = { i : 1 ≤ i ≤ min(m,n),　Tₙ₋ᵢ = ∅ または Tₙ₋ᵢ = {i} }

式を小さい山から順に厳密に計算します。大きな n では、直近 m 行の状態が再出現した後の周期を見つけて残りを飛ばします。
